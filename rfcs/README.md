# RFCs

RFCs capture architectural decisions and hypotheses that should survive individual experiments. Because this repository is a laboratory, accepted RFCs may still be revised when executable evidence disproves an assumption.

## RFC expectations

An RFC should state the problem, decision/hypothesis, invariants, failure/safety behavior, alternatives, and known pressure. Avoid presenting roadmap ideas as implemented capabilities.
